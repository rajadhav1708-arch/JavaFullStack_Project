How to Run the Project

Prerequisites

Make sure the following are installed on your system:

- Git
- Node.js
- npm

Steps

1. Clone the Repository

git clone YOUR_REPOSITORY_URL

2. Navigate to the Project Directory

cd Cattle-feed

3. Install Dependencies

npm install

4. Start the Development Server

npm run dev

5. Open the Application

After the server starts, open the local URL displayed in the terminal.

Usually:

http://localhost:5173/

Notes

- Run all commands from the project root directory.
- "npm install" is required only after cloning the project or when dependencies are updated.
- Keep the terminal running while using the development server.
